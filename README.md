# kalja

**Finnish-focused text mutation and human-input fuzzing**

kalja is a Python library for generating synthetic text corruption for
robustness testing, with particularly good support for Finnish keyboard
behavior.

It is intended for testing search systems, fuzzy matching, forms, parsers,
NLP pipelines, typo correction, normalization systems, and other software
that processes human-written text.

> kalja generates synthetic mutations. It is not a model of intoxication,
> actual Finnish language behavior, or any particular group of people.

## Status

kalja is currently under development toward its first `0.1.0` release.
